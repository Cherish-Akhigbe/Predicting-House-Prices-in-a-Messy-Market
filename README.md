# Predicting House Prices in a Messy Market

## Project Overview
This project focuses on predicting house sale prices using machine learning, with emphasis on data preprocessing, feature relationships, and regression model evaluation.

## Objectives
- Explore factors associated with house prices.
- Handle data quality and preprocessing challenges.
- Investigate relationships between numerical features.
- Build and evaluate regression models.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Workflow
1. Data exploration and cleaning.
2. Feature selection and preprocessing.
3. Analysis of multicollinearity.
4. Log transformation of the target variable.
5. Feature scaling with StandardScaler.
6. Linear Regression and Ridge Regression.
7. Five-fold cross-validation.

## Model Evaluation
- Linear Regression RMSE: approximately 0.15444.
- Ridge Regression RMSE: approximately 0.15443.

These are the recorded RMSE values; the evaluation scale should be stated explicitly in the final version.
